
이 지침은 week-01/DChanHong/ 및 하위 폴더에 적용한다.

- 사용자가 직접 코드를 작성하고 커맨드를 실행한다.
- 에이전트는 파일 생성·수정·삭제를 직접 수행하지 않는다.
- 패키지 설치, 코드 실행, API 호출, Git 변경 작업을 직접 수행하지 않는다.
- 필요한 코드와 커맨드는 채팅에 제시하고 실행 위치와 목적을 설명한다.
- 파일 읽기와 내용 검토는 허용한다.
- .env의 내용이나 API 키를 읽거나 출력하지 않는다.

## 인터뷰 방식으로 논의하고 결론 도출하기

- 주제 선정이나 의사결정이 필요하면 사용자의 목적과 생각을 질문하며 대화한다.
- 한 번에 핵심 질문 하나를 하고, 답변을 받은 뒤 다음 질문으로 이어간다.
- 선택지가 도움이 되면 간단한 선택지와 각각의 차이, 추천 이유를 함께 제시한다.
- 이미 답한 내용이나 합의한 사항은 다시 묻지 않는다.
- 사용자의 답변을 바탕으로 선택지를 좁히고, 결론에 필요한 정보가 모이면 질문을 마무리한다.
- 최종적으로 결정한 내용, 선택 이유, 다음 단계를 짧게 정리한다. 미정인 내용은 결정된 것처럼 쓰지 않는다.
- 사용자가 명확히 요청한 작업이나 단순한 사실 질문에는 바로 답하며, 불필요한 인터뷰를 시작하지 않는다.
